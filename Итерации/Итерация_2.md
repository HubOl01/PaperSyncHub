## Обзор конкурентов

**1. Typst** – редактор шаблонов, который предназначен для написания и форматирования научных текстов и математических формул под требования журнала или по ГОСТу.
Соответствие задачам:
  * Поддерживает скриптинг (встроенный язык, похож на Rust/Python), интеграцию с Quarto (для Python/R/Julia), импорт данных через пакеты. Можно встраивать код и результаты.
  * Отличное автоматическое форматирование, шаблоны (templates), bibliography. Легко создавать кастомные шаблоны. Поддержка PDF/HTML и экспорта.
  * Быстрая компиляция, Git-интеграция, коллаборация (в веб-версии). Локальный CLI + веб/десктоп app.

***Typst хорошо подходит для форматирования и шаблонов, но слабый в интеграции вычислений и данных. Из минусов, это не полноценная IDE с запуском скриптов внутри документа. Малый фокус на контроле версий данных. На данный момент слабее принят журналами по сравнению с LaTeX.***

---

**2. Quarto** – инструмент для создания воспроизводимых документов, статей, книг, презентаций и веб-сайтов на основе языка разметки Markdown, кода (Python, R, Julia) и системы Pandoc.  Открытая система научного и технического паблишинга. Вы пишете текст в формате .qmd (Quarto Markdown) и встраиваете туда блоки с кодом. При компиляции Quarto выполняет код, берет свежие результаты (графики, таблицы, вычисления) и вставляет их в итоговый документ.
Соответствие задачам:
Соответствие задачам:
  * Отличная поддержка Python, R, Julia, Observable. Встраиваемый код, выполнение скриптов, импорт CSV/JSON/XLS и т.д. Динамические отчёты (code + output + текст).
  * Работает с Git.
  * Автоматическое форматирование под журналы (много шаблонов), PDF/Word/HTML/ePub. Легко создавать кастомные шаблоны.

***Quarto является мощным кросс-платформенным приложением, плюсом которого является возможность интеграции внешних моделей для генерации кода/текста. Из минусов – больше CLI + редактор (VS Code/RStudio/Jupyter), а не монолитный десктопный IDE с встроенным всем. Нет глубокого встроенного контроля версий данных (нужен DVC).***

---

**3. JupyterLab** – современная веб-среда разработки для работы с кодом, данными и научными блокнотами (Jupyter Notebook). Она объединяет классические интерактивные блокноты, текстовый редактор, терминал и файловый менеджер в одном удобном интерфейсе с вкладками. 
Соответствие задачам:
  * Полноценная вычислительная среда, импорт любых форматов, визуализации, inline результаты.
  * Работает с Git.
  * Экспорт в PDF/LaTeX/HTML.

***JupyterLab является бесплатным, локальным приложением с огромной экосистемой. Curvenote добавляет коллаборацию и переход от notebook к полноценной статье. Из минусов – Notebooks могут становиться "messy" (линейный код). Не самый удобный для длинных нарративных статей без дополнительных инструментов. Библиография через Zotero/Jupyter extensions.***

---

**4. Org-mode (Emacs)** – это популярный режим текстового редактора GNU Emacs, созданный для ведения заметок, планирования задач (GTD), управления проектами и подготовки документов. Он использует простые текстовые файлы с расширением .org, которые легко читаются человеком даже без использования специального софта. 
Соответствие задачам:
  * Org-Babel – выполнение кода (десятки языков) прямо в документе, результаты inline, импорт данных.
  * Работает с Git.
  * Экспорт в LaTeX/PDF/HTML/Word с шаблонами (org-export). Кастомные templates легко писать.
    
***Org-mode полностью локальный, гибкий, один файл может содержать всё (заметки + код + статья). Из минусов, это не десктопное GUI-приложение.***

---

**5. Manubot** – система с открытым исходным кодом, предназначенная для автоматизированного создания научных статей и академических публикаций. Она совмещает процесс написания текстов с принципами разработки программного обеспечения. Статьи пишутся в формате Markdown и хранятся в репозитории на GitHub (или GitLab), что позволяет отслеживать все изменения.
Соответствие задачам:
  * Git-based (отличный контроль версий всего проекта).
  * Автоматическая генерация (CI/CD), citations, figures из данных/кода.
  * Markdown + Pandoc для форматирования.
  * Сильный акцент на reproducibility и открытость.
    
***Минусы данного редактора, то, что он больше workflow, чем готовое приложение. Требует настройки.***

---

**6. Overleaf** – это популярный облачный онлайн-редактор для работы с документами на языке разметки LaTeX. Он позволяет создавать академические статьи, книги и отчеты со сложными математическими формулами, не устанавливая программы на компьютер. 
Соответствие задачам:
  * Хорошие шаблоны журналов, bibliography (Zotero/Mendeley), Git sync, история версий.
  * Слаб в встроенных вычислениях (нужен внешний код).
    
***Overleaf  это больше про вёрстку, чем про вычисления.***
